# 5. 主动消息

主动消息由调度器触发，仍需经过与普通回复相同的模型线路、格式清理与发送管线。

## 触发条件

建议同时满足：

- 用户至少 30 分钟没有发新消息
- 当前没有待合并消息或正在生成的回复
- 距离上一条主动消息达到最小间隔
- 当天发送次数没有超过上限
- 随机时间槽或明确计划已经到达

```js
function canSendProactive(chat, now) {
  return chat.proactiveEnabled
    && now - chat.lastUserMessageAt >= 30 * 60_000
    && now - chat.lastProactiveAt >= 30 * 60_000
    && chat.proactiveCountToday < 10;
}
```

## 上下文

把最近几轮对话和压缩后的长期背景交给模型，同时明确这是一次主动私聊。提示词应要求模型只输出最终正文，不讨论发送能力、后台任务或系统权限。

生成后增加一道发送前检查，拦截以下内容：

- “我无法主动联系你”一类能力说明
- “要不要我帮你拟一条消息”一类代写话术
- 虚构用户此刻正在做什么
- 虚构机器人刚开会、下班或回家等现实经历

检查失败时可使用一条短而自然的本地兜底文案，或放弃本次发送并稍后重试。

用户一旦发来新消息，应立刻更新 `lastUserMessageAt`。主动消息定时器不能阻塞正常回复。
